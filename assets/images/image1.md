# CLAP-Jules Audio Plugin GUI

This image represents the soothe2-style professional audio plugin interface implemented in this project.

## Interface Layout

### Left Side Controls:
- Large DEPTH knob (main control)
- SHARPNESS and SELECTIVITY knobs  
- ATTACK and RELEASE envelope controls
- MODE radio buttons (Soft/Medium/Hard)
- STEREO LINK and QUALITY toggles
- BALANCE slider

### Right Side:
- Interactive EQ curve display
- Real-time frequency response visualization
- Draggable EQ points with undo/redo functionality
- Professional dark color scheme

### Bottom Controls:
- OUTPUT GAIN knob
- BYPASS button
- EQ control buttons (RESET/UNDO/REDO)
